# ESTÁNDARES DOCUMENTACIÓN

## Estructura de Documentos
- Usar Markdown con extensión .md
- Encabezados en español
- Incluir metadata YAML frontmatter

## Diagramas
- Fuentes en PlantUML (.puml)
- Exportar a SVG para visualización
- Versionar ambos (fuente y exportado)

## Convención de Commits
feat(docs): agregar documento de arquitectura
fix(docs): corriger error en diagrama de contexto  
docs: actualizar decision log técnico
